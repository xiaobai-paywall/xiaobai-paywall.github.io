# 商业变现

iOS / GP 订阅页与订阅策略的方案储备库。

## 订阅页图库

截图瀑布流 + 自定义标签 + 组合筛选。

**打开**：双击 `订阅页图库.html`（推荐 Chrome 或 Edge）。

**上传**：点「上传图片」直接选文件，或把图片拖进页面、⌘V 粘贴截图，不需要任何授权。支持 PNG、JPG、WebP、GIF，不支持视频。上传时会自动压缩：宽度超过 1290px 的会缩小，并转成 WebP（GIF 保留原样）。每张图生成一个方案；打开方案后可以追加图片（如挽留页）。

**打标签**：上传后会弹出「快速打标签」，填来源、点几个标签，会同时打到这次上传的所有文件上；不想打可以直接点「完成」。之后打开单个方案也能改。

**搜索**：顶部搜索框（按 `/` 快速聚焦），能搜来源、价格、标签、备注、文件名，多个关键词用空格隔开。

**放大浏览**：点卡片进入大图模式，右侧显示价格、标签、备注。点图片放大 2 倍看细节；← → 切换方案，↑ ↓ 切换同一方案的多张图，E 编辑，Esc 关闭。可以「复制图片」直接粘贴到 PRD / Figma，或「下载原文件」。

**对比**：卡片左上角勾选（或按住 ⌘ 点卡片），底部出现操作栏：「并排对比」把几个方案的图、价格、标签放在一起看；「批量打标签」一次给选中的方案打标签。

**价格信息**：每个方案可以单独记一行价格，如「首月 $2.99 → $19.99/月」，卡片上直接显示，也能被搜索到。

**存储**：素材默认保存在本机浏览器里（和「小白收息」一样），清除浏览器数据会丢失。想在硬盘上也留一份，点右上角「备份到素材文件夹（可选）」，选择 `订阅页图库/素材` 并允许编辑，之后会自动同步，已有的素材也会补备份过去。

**管理标签**：右上角「管理标签」，点名字改名、× 删除、「＋ 添加」新建。

**筛选**：左侧点标签。同一分组内多选是「或」，不同分组之间是「且」。

## 数据存在哪里

```
商业变现/
├── 订阅页图库.html        # 入口，双击打开
├── 订阅页图库/
│   ├── index.html
│   ├── assets/            # 页面样式和脚本
│   └── 素材/              # 所有上传的截图 + data.js（方案和标签数据）
├── 待整理/                # 丢给 AI 批量导入的截图
└── docs/                  # 设计文档
```

备份或换电脑：复制整个 `商业变现` 文件夹即可。

## 同步到 GitHub

本文件夹是独立的 Git 仓库，对应 GitHub 组织 `xiaobai-paywall` 下的公开仓库 `xiaobai-paywall.github.io`，推送后自动发布到 <https://xiaobai-paywall.github.io>（网页版只读：只显示已推送的素材，网页上新上传的图只存在那个浏览器里）。

注意：仓库和网页都是公开的，推送上去的截图和标签任何人都能看到。

1. 先在图库里点「备份到素材文件夹」，图片才会写进 `素材/`，Git 才能看到。
2. 在 Cursor 里说「提交并推送图库」，或者在终端执行：

```bash
cd ~/Documents/cursor/商业变现
git add -A && git commit -m "更新素材" && git push
```

换电脑：`gh repo clone xiaobai-paywall/xiaobai-paywall.github.io 商业变现`，双击 `订阅页图库.html` 就能看到全部方案；之后想继续同步，再点一次「备份到素材文件夹」选择 `订阅页图库/素材`。
