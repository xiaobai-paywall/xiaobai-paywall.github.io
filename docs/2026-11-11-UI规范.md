# UI 规范

加新功能、改样式之前先看这份。原则只有一条：**用已有的 token 和组件，不要新造一个差不多的。**

- token 定义在 `assets/tokens.css`，`hub.css`、`scan.css` 共用；加载顺序是 `style.css → tokens.css → hub.css → scan.css`。
- 旧变量名（`--card`、`--muted`、`--gold` 等）已经指向新 token，旧样式不用一次改完，但**新写的样式只用新名字**。
- 改了任何 CSS / JS，把 `index.html` 里所有 `?v=` 改成当天日期（如 `?v=20261112`，同一天第二次改加 `b`、`c`），否则浏览器可能拿新的 JS 配旧的 CSS。

## 1. 颜色

### 底色和表面（越往上越亮）

| token | 值 | 用在哪 |
| --- | --- | --- |
| `--bg` | `#070b16` | 页面底色 |
| `--surface-0` | `#0b1120` | 代码块等嵌在卡片里更深的一层 |
| `--surface-1` | `#0e1626` | 卡片、表格、控件底色 |
| `--surface-2` | `#131c30` | 面板、下拉菜单、打开状态的控件 |
| `--zebra` | 白 1.8% | 表格偶数行 |

### 线

| token | 用在哪 |
| --- | --- |
| `--line-faint` | 表格行线、卡片内部分隔 |
| `--line-soft` | 卡片、区块外框 |
| `--line` | 可点控件的默认边框、表头下边线 |
| `--line-strong` | 可点控件悬停、下拉打开时的边框 |

### 文字

| token | 用在哪 | 在 surface-2 上的对比度 |
| --- | --- | --- |
| `--text` | 标题、数字、主要内容 | 15:1 |
| `--text-2` | 正文说明、未选中的按钮文字 | 7.8:1 |
| `--text-3` | 标签名、单位、次要说明 | 5.4:1 |

不要再用更暗的灰色写文字；需要更弱就缩小字号，不要降对比度。

### 语义色：一个颜色只表示一件事

| 颜色 | token | 只用于 |
| --- | --- | --- |
| 青 | `--brand-rgb`（`rgb(var(--brand-rgb))`） | 选中、主操作、正向判断（可复制、高得分、前 x%） |
| 金 | `--money` | 钱：价格、最贵内购。**不要**拿来做强调或警告 |
| 蓝 | `--geo` | 海外 / 多国：N 国畅销前 10、美国也在榜、美国占比低 |
| 绿 / 红 | `--up` / `--down` | 名次涨跌 |
| 分类色 | `genreColor(gid)` → `--g` | 只给分类标签和分类色点用 |

带透明度的写法：`rgba(var(--brand-rgb), .12)`。选中态底色用 .10–.14，悬停 .2，边框 .4–.5。

## 2. 字号

只用 6 档，不要写 10.5px、12.5px 这类半档：

| token | 大小 | 用在哪 |
| --- | --- | --- |
| `--fs-1` | 11px | 标签、表头说明、底部 Tab 文字。**功能性文字的下限** |
| `--fs-2` | 12px | 次要信息、表格小字、筛选标签 |
| `--fs-3` | 13px | 正文、按钮、表格内容 |
| `--fs-4` | 14px | 应用名、卡片标题、卡片里的数字 |
| `--fs-5` | 16px | 区块标题、手机上的指标数字 |
| `--fs-6` | 20px | 指标栏数字 |

- 所有数字加 `font-variant-numeric: tabular-nums`，表格里数字右对齐。
- 字重：正文 400–500，按钮和标签 600，标题和关键数字 700。

## 3. 间距、圆角、阴影、动效

- **间距**：`--sp-1` 4 / `--sp-2` 8 / `--sp-3` 12 / `--sp-4` 16 / `--sp-5` 20 / `--sp-6` 24 / `--sp-8` 32。相关的东西 8 以内，不同的区块 16–20。
- **圆角**：`--r-1` 4 标签 / `--r-2` 8 按钮和控件 / `--r-3` 12 卡片和表格 / `--r-4` 16 大区块和手机底部菜单 / `--r-pill` 胶囊。
- **阴影**：`--sh-1` 按钮内的小浮起 / `--sh-2` 浮起的卡片 / `--sh-3` 下拉菜单、弹窗。不要用零偏移的彩色光晕。
- **焦点**：全局 `:focus-visible` 已经套了 `--focus-ring`，不要写 `outline: none` 去掉它。表格行、菜单选项用内描边代替。
- **动效**：颜色、边框切换用 `--dur-1`（.12s），展开、位移用 `--dur-2`（.2s）。按下统一下沉 1px（`tokens.css` 里已经对常用控件生效）。

## 4. 组件

### 按钮

| 用途 | 写法 |
| --- | --- |
| 普通按钮 | `.pill-btn` |
| 唯一的主操作 | `.pill-btn.primary`（一屏最多一个） |
| 青色次要操作（清空筛选等） | `.pill-btn.sc-act` |
| 两三个互斥选项 | `.seg` 里放 `.seg-btn`，选中加 `.active` |
| 视图切换（美国榜 / 其他海外榜） | `.sc-view`，选中加 `.active` |

可点控件高度：桌面 36px，手机 40px 起，手机菜单选项 44px。

### 下拉菜单

不要用原生 `<select>`（macOS 上是系统浅色菜单，长列表卡）。用 `scan.js` 里的 `dropdown()`：

```js
dropdown(key, '分类', [{ v: 'all', t: '全部', n: 84 }, ...], 当前值, 'sc-sel');
```

- `t` 是 HTML，名字要先 `esc()`。
- `n` 是右侧数量，可省略。超过 10 项自动排成两列。
- 选中后的处理写在 `ddPick(key, v)` 里。
- 手机上自动变成底部弹出的菜单，带遮罩。

### 标签：四种含义，四种样子

| 含义 | 例子 | class | 样子 |
| --- | --- | --- | --- |
| 判断 | 可复制、有苗头 | `.sc-copy` / `.sc-copy.hi` | 青色实底 |
| 海外 / 多国 | N 国畅销前 10、美国也在榜 | `.sc-gross` / `.sc-in-us` | 蓝色实底 |
| 属性 | 年、永久、分类体量 | `.sc-per` / `.sc-size` | 中性灰底 |
| 可信度 | 外推、推算、放宽、自动摘录 | `.sc-loose` / `.sc-guess` / `.sc-auto` | 虚线框、弱文字 |

统一 11px、圆角 4px、行高 18px。新标签先想它属于哪一类，不要发明第五种颜色。分类标签 `.sc-tag` 单独一套，颜色来自分类色。

### 当前筛选条件

表格上方的 `.sc-on` 胶囊：`功能：xxx ×`。点 × 去掉单个条件（`data-clear="字段名"`），两个以上条件时出现「全部清除」（`data-reset`）。文字超过 220px 截断，`title` 放全文。

### 卡片和区块

- 卡片：`--surface-1` 底 + `--line-soft` 边框 + `--r-3` 圆角，内边距 `--sp-3`。
- 可点的卡片：悬停边框换成青色 .4，上浮 1px；选中边框青色 .75、底色青色 .07。
- 卡片里放数字用 `<dl>`：`dt` 11px `--text-3`，`dd` 14px 粗体。

### 表格

- 单元格上下 9px、左右 10px，偶数行斑马纹，悬停整行淡青。
- 文字列左对齐，数字列右对齐等宽。每格一个主数字（`<b>`），下面一行 `.sc-sm` 小字放次要信息。
- 表头固定在顶部，可排序的列用 `<th data-sort>` 里放 `<button>`，当前排序列带 `aria-sort`。
- 641–1240px 表格横向滚动，能继续滚的一侧会渐隐（`scrollEdges()` 切换 `can-l` / `can-r`）。
- 手机（≤640px）变卡片：应用 + 得分在第一行，其余字段三列排，`data-l` 属性就是字段名。

## 5. 状态

每个列表、每个控件都要想到这几种：

| 状态 | 怎么做 |
| --- | --- |
| 没有数据 | `.sc-empty`：一句标题 + 一句下一步该做什么 + 可复制的命令 |
| 筛选无结果 | `.sc-none-in`：标题「没有符合当前条件的产品」+ 建议 + 「清空全部条件」按钮；没有筛选条件时只说明原因 |
| 加载中 | 按钮加 `.busy`（图标转圈）、`disabled`，文字改成「检查中…」；结束后 `.done` 显示结果 1.8 秒 |
| 图片未加载 | `<img>` 给 `--surface-2` 底色，固定宽高，不让布局跳 |
| 悬停 | 边框 `--line` → `--line-strong`，文字 `--text-2` → `--text` |
| 按下 | 下沉 1px；手机底部 Tab 图标缩到 .92 |
| 键盘焦点 | `--focus-ring`；表格行、菜单选项用内描边 |
| 禁用 | 透明度 .4，`cursor: not-allowed`，并在 `title` 里说明原因 |

触屏设备没有悬停：上浮类效果在 `@media (hover: none)` 下已经关掉。

## 6. 长文本

- 单行截断：`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`，被截断的地方都要有 `title` 放全文。
- 手机卡片里应用名最多 2 行（`-webkit-line-clamp: 2`），开发者名 1 行。
- 段落说明加 `text-wrap: pretty`，避免最后一行只剩一两个字。
- 不要靠固定宽度容纳文案，名字随时会变长。

## 7. 手机端（≤640px）

- 页面左右留 12px，底部给 Tab 留 `86px + 安全区`。
- 横向一排放不下的选项（视图、分类）横向滚动，不折行。
- 浮层（下拉、详情）从底部弹出，离底部 Tab 留出空间。
- 底部 Tab：每项至少 50px 高，文字 11px，当前项加 `aria-current="page"`。
- 每次改完至少在 390px 宽检查：没有横向溢出（`document.documentElement.scrollWidth` 等于视口宽度），可点控件不小于 36px。

## 8. 有意保留的例外

这些是品牌识别，自动检测会报，但保留不改：顶部 Logo 的光晕和动画、「商业变现」渐变标题、面板顶部 3px 色条、左侧导航的色条和渐变底。

## 9. 还没跟上这份规范的地方

- 详情面板（`.sc-dh`、`.sc-tiles`、`.sc-blk`、`.sc-geo`、`.sc-iap`）还在用 11.5px、12.5px 等半档字号和旧变量名。
- 「收集素材」（`订阅页图库/assets/style.css`、`app.js`）整体还是旧写法。
- 改这两块时按本文替换，不要在旧写法上继续加。
